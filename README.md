# Thin Ice Express 🚂❄️

A 2D game built with **Godot 4**.

---

## 📖 About the Game

*Thin Ice Express* is a fast-paced game where players navigate a train/locomotive across hazardous icy tracks. Balance speed and momentum while avoiding structural failures and obstacles along the route.

> *Note: This project is currently in active early development.*

---

## 🛠️ Built With

* **Game Engine:** [Godot Engine 4.x](https://godotengine.org/)
* **Language:** GDScript
* **Version Control:** Git + [Git LFS](https://git-lfs.com/)

---

## 🚀 Getting Started

### Prerequisites

1. **Godot Engine 4.x** (Standard Edition)
2. **Git** & **Git LFS**

### Installation & Setup

1. **Install Git LFS** (one-time setup):
   ```bash
   git lfs install
   ```

2. **Clone the Repository:**
   ```bash
   git clone https://github.com/Light-Wave/thin-ice-express.git
   cd thin-ice-express
   ```

3. **Open in Godot:**
   - Launch Godot Engine 4.
   - Click **Import** and select the `project.godot` file in the cloned directory.
   - Click **Import & Edit**.
